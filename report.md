BST: Inorder traversal gives sorted output. Worst case height = n (skewed tree).

Heap: Used in scheduling, insert/extract O(log n).

Graph BFS/DFS: BFS uses queue, DFS uses recursion/stack. Complexity O(V+E).

Hash Table: Collisions handled by chaining. Load factor matters.

Trie: Useful for autocomplete. Prefix queries efficient.

Bloom Filter: Probabilistic membership, allows false positives but never false negatives.
